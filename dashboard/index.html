Token Radar

Every protocol that records no token, ranked by what its token would be worth if the record stayed as it is. The board keeps the ones still to come apart from the ones whose token already trades.

How the value is worked out

Implied value starts at 30% of a protocol’s TVL. Seven-day growth moves it: growth is clamped to −50% … +100% and counts at 60% weight. How long the protocol has run with no token moves it again, from 0.70 for a new listing to 1.20 after four years. Running on more chains adds 4% a chain, up to five extra chains. Nothing is special-cased by name: the same rule scores every row.

A protocol “records no token” when its DefiLlama record carries no market cap, no CoinGecko id and no symbol. That is the record’s word, not proof it has none. The board never predicts whether or when a token is issued.
